# Robust Vehicle Routing Problem with Time Window Assignments (RVRP-TWA)

The width and placement of time windows are endogenous decision variables. The model enables trading off narrower windows (reducing risk of violation) against wider windows (increasing feasibility but raising violation probability under uncertainty).

## Uncertainty Model
Travel times are treated as uncertain. The paper models this using robust optimization, where "uncertain travel times" create scenarios of potential delay. The approach hedges against worst-case deviations while maintaining computational tractability.

## Objective Function
The optimization balances two competing goals: minimizing expected travel time costs while managing the risk of time-window violations. The formulation trades operational efficiency against service reliability through the time-window width decisions.

A key theoretical contribution establishes that "the time-window assignment subproblem" exhibits convexity properties, enabling efficient solution methods rather than requiring exhaustive search over window configurations.

# Recoverable Robust Optimization with Commitment: Formal Model and Main Results

## The Two-Stage Model with Commitment

**Stage 1 (First-stage decision):** Select a solution $S \in \mathcal{F}$ from the feasible solution set of a combinatorial optimization problem.

**Stage 2 (Disruption and recovery):** An adversary deletes at most $k$ elements from $S$, yielding $S \setminus F$. The decision-maker then adds at most $\ell$ new elements $R$ from the remaining ground set, producing a second-stage solution $S' = (S \setminus F) \cup R$ that must remain feasible.

**The Commitment Constraint:** The defining feature is that "non-failing elements of the initial solution" must be preserved—no elements from $S \setminus F$ can be removed during recovery. This distinguishes the model from standard recourse approaches where solutions can be substantially restructured.

## Formal Objective

The goal is to solve:

$$\max_{S \in \mathcal{F}} \min_{F \subseteq E, |F| \leq k} \max_{\substack{R \subseteq E \setminus F, |R| \leq \ell \\ (S \setminus F) \cup R \in \mathcal{F}}} w((S \setminus F) \cup R)$$

This is a max-min-max formulation where the adversary acts with perfect information about optimal recourse actions.

## Motivating Application: Reservation Systems

The paper motivates the model through "reservation-based systems—such as hotel bookings, rental car reservations, or airline seat reservations." When customers cancel reservations, the supplier can add new customers to fill vacancies, but cannot revoke existing confirmed bookings. This capture the practical need to honor prior commitments while adapting to disruptions.

## Main Theoretical Results

**Theorem 1 (Robust Matroid):** For the maximum-weight independent set problem in a matroid, when $k \leq \ell$, an optimal solution to the nominal problem is also optimal for the robust counterpart. The result is tight: matroids are "exactly those structures" with this robustness property, and the property fails for $k > \ell$ or non-matroid structures.

**Theorem 2 (Hardness - Robust Bipartite Matching):** The robust counterpart of unweighted maximum matching in bipartite graphs is NP-complete, even in the $(1,1)$-case. This reveals that matroid intersection problems (which reduce to matching) behave fundamentally differently from single-matroid problems.

**Theorem 3 (Hardness - Robust Bipartite Stable Set):** The weighted version of robust stable set in bipartite graphs is NP-hard. However, the unweighted case remains polynomial-time solvable.

**Theorem 4 (Polynomial Cases - Interval Scheduling):** There exist polynomial-time algorithms for $(1,p)$-Robust Interval Scheduling (stable sets in interval graphs) for any constant $p$. The key technique involves reduction to a bounded-regret version and a novel "Interval Scheduling with Colors" intermediate problem solved via dynamic programming.

# Split Conformal Predictive System (SCPS) Explained

## Algorithm Steps

SCPS operates in four main phases:

**1. Data Partitioning:** Split training data into two disjoint sets—a proper training set and a calibration set. This separation ensures the model is evaluated on genuinely unseen data during uncertainty quantification.

**2. Model Training:** Train any regression model on the proper training set to produce point predictions h(x) for new inputs.

**3. Calibration Score Computation:** For a test input and each calibration example, compute scores as: C_j = h(x) + (y_j - h(x_j)). This combines the test prediction with historical prediction errors, simulating plausible outcomes based on past model mistakes.

**4. Distribution Construction:** Sort the calibration scores, then define the estimated CDF using piecewise-linear interpolation between sorted scores. The paper states: "the estimated CDF can be computed as follows" with boundary conditions at negative and positive infinity.

The resulting CDF F̂(y|x) produces a proper probability distribution over possible fulfillment deviations. Any quantile can be extracted directly—for example, the 90th percentile provides a conservative delivery estimate, while the 50th percentile gives a median prediction.

## Coverage Guarantee

SCPS provides a "finite-sample, distribution-free coverage" guarantee assuming exchangeability (data point order doesn't affect the underlying probability).
